The mesh (snapshot)

The default mesh's uniform cell diagonal breaks y-mirror symmetry — the pattern is ~3.8× brighter on one side of a symmetric scene (a lattice artifact, rung 3.5 / #252). The repaired mesh alternates the diagonals: same scene, same solver, y-symmetric to machine precision. Live /sim streams the default mesh only.
